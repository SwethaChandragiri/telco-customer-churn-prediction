# 📞 Telecom Customer Churn Prediction

A machine learning web app that predicts whether a telecom customer is likely to leave (churn) or continue using the service.

---

## 🚀 Live Demo
Try the deployed app here:  
👉 **[Telecom Customer Churn Predictor](https://telco-customer-churn-prediction-01.streamlit.app)**

---

## 📌 About the Project
Customer churn means customers stopping their subscription or service. Predicting churn helps companies reach out to high-risk customers with better offers before they leave.

### What this app does:
- Takes customer details like contract type, monthly charges, tenure, and internet services.
- Uses a machine learning model to estimate the churn probability.
- Warns if the customer is at high risk of leaving.
